Avoid repeating the exact same parameter combination across iterations; each iteration should, as far as practical, consume new bytes and exercise a different configuration or state transition.

Summary:
Sends (writes) an item to the front or the back of a queue.
xQueueSend() and xQueueSendToBack() perform the same operation so are equivalent.
Both send data to the back of a queue.  xQueueSend() was the original version , and it is now
recommended to use xQueueSendToBack() in it s place.
